# Workflow 與 Agent 的差異及設計原則

- 官方原文：[Building effective agents](https://www.anthropic.com/research/building-effective-agents)
- 來源代碼：[S02]
- 摘要檔：[raw/S02.md](../raw/S02.md)

## 已核對的重點

### What are agents?
Anthropic 區分：Workflow 的模型與工具依預定程式路徑運作；Agent 則由模型動態決定處理步驟及工具使用。 [S02]

### When (and when not) to use agents
應先選可達到目標的最簡方案；工作流程較可預測，代理更有彈性，但增加複雜度、成本與延遲。 [S02]

### Building blocks, workflows, and agents
增強型 LLM 可加入檢索、工具及記憶等能力；這些是可加入的能力，不應表述為每個 Agent 必然都具備。 [S02]

### Workflow: Prompt chaining
鏈式工作流程可在階段之間設定程式品質關卡，讓錯誤在早期被發現。 [S02]

## 定義差異說明
Anthropic 強調固定路徑 Workflow 與動態路徑 Agent 的架構區別；OpenAI S01 側重模型控制多步驟流程與工具使用。兩者的文字側重不同，不宜推論「每個 Agent 必須有永久記憶」等未支持主張。[S02][S01]
