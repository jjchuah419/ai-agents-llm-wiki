# AI Agent 的定義、三項基本構件與使用時機

## 已核對的重點

### What is an agent?
OpenAI 將 Agent 描述為能在使用者授權範圍內，透過模型決策及工具使用來執行工作流程的系統。與只回覆文字的一般單輪聊天應用不同，模型參與流程控制。 [S01]

### Agent design foundations
基礎構件為模型（model）、工具（tools）及指示（instructions），其組合使系統能決策並與外部環境互動。 [S01]

### When should you build an agent?
面對複雜判斷、不易維護的規則或非結構化資料時，可考慮代理；若確定性流程足夠，未必需要代理。 [S01]

### Defining tools
工具可協助讀取資料或執行動作，因此需要權限、驗證和風險控管。 [S01]

## 示意案例（非原文真實個案）
學生希望整理課程公告；一般聊天機器人可以提供方法，而具備授權工具的 Agent 可以查詢指定資料、整理並輸出待確認清單。**此為示意案例，不代表任何產品必然具備該功能。** [S01]
