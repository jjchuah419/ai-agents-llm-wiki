## 重要知識點

### 1. 代理的基本循環
LangChain 將 Agent 描述為模型在任務未完成時，反覆使用工具的系統；工具回傳結果後，模型可繼續做決策。 [S03]

來源定位：*Agents：An agent is a model calling tools in a loop until a given task is complete.*。

### 2. 周邊配置（Harness）
文件同時說明，工具循環不是全部：提示詞、工具與 middleware 等周邊配置會塑造模型的行為。 [S03]

來源定位：*Agents：A harness is everything around that loop.*。

### 3. 不能過度推論
這是 LangChain 文件對其 Agent 架構的說明，不代表所有 AI Agent 都必須使用該框架，亦不能據此宣稱正確率或執行成本。 [S03]

來源定位：*依原文適用範圍整理*。

## 不同來源的角度
與 [S02] 的差別：LangChain 著重模型與工具循環的實作；Anthropic 著重「固定 workflow」和「模型動態決策」的區別。兩者角度不同，並非必然互斥。
