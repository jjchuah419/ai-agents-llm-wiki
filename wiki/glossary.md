# 重要術語（五篇來源整合版）

| 中文名稱 | 英文術語 | 入門解釋 | 依據 |
|---|---|---|---|
| 人工智慧代理 | AI Agent | 能在授權條件下運用模型決策與工具推進任務的系統 | [S01] |
| 工作流程 | Workflow | 依預設步驟運行的工作安排；若含 LLM 與工具，控制路徑通常由程式預先決定 | [S02] |
| 大型語言模型 | Large Language Model (LLM) | 用於理解文字與推理、協助代理作出下一步決定的模型 | [S01] |
| 工具使用 | Tool Use | 讓系統查詢資料或執行外部動作的能力 | [S01] |
| 指示 | Instructions | 約束代理任務、行為與安全邊界的規則 | [S01] |
| 記憶 | Memory | 可選擇加入 LLM 系統的歷史或狀態資訊能力，並非所有代理的必要條件 | [S02] |
| 協調器 | Orchestrator | 安排任務流程、工具路由及組件間的資訊傳遞 | [S05] |
| 短期記憶 | Short-term memory | 維持單次會話內狀態及歷史 | [S04] |
| 長期記憶 | Long-term memory | 跨會話儲存或取回資訊的額外機制 | [S04] |
| 執行框架 | Harness | 包覆模型工具循環的提示詞、工具及 middleware 等控制層 | [S03] |
