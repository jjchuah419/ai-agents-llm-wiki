# AI Agents 是什麼？｜LLM Wiki 最終整理版

## 如何開啟
1. 雙擊 `slides/ai_agents_intro.html`，使用 Chrome/Safari 瀏覽 12 頁簡報。
2. 使用左右方向鍵或下方按鈕切換。
3. 開啟 `wiki/index.md` 查看五篇已查閱來源的 Wiki 條目與術語表。
4. 在專案根目錄執行 `python3 scripts/check.py` 及 `python3 scripts/check_final.py` 重新檢查。
5. 繳交內容請參考 `reports/submission.md`；請自行填入學校、系級、學號、姓名。

**說明：** raw 內容為官方資料的人工改寫摘要，非全文資料下載。對外公開網址及 Git commit 不是在此環境中自動產生，請勿冒稱已完成。
