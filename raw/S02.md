## 章節與可支持的主張

### 1. What are agents?
- 來源位置：官方文章章節「What are agents?」
- 摘要：Anthropic 區分：Workflow 的模型與工具依預定程式路徑運作；Agent 則由模型動態決定處理步驟及工具使用。 [S02]

### 2. When (and when not) to use agents
- 來源位置：官方文章章節「When (and when not) to use agents」
- 摘要：應先選可達到目標的最簡方案；工作流程較可預測，代理更有彈性，但增加複雜度、成本與延遲。 [S02]

### 3. Building blocks, workflows, and agents
- 來源位置：官方文章章節「Building blocks, workflows, and agents」
- 摘要：增強型 LLM 可加入檢索、工具及記憶等能力；這些是可加入的能力，不應表述為每個 Agent 必然都具備。 [S02]

### 4. Workflow: Prompt chaining
- 來源位置：官方文章章節「Workflow: Prompt chaining」
- 摘要：鏈式工作流程可在階段之間設定程式品質關卡，讓錯誤在早期被發現。 [S02]
