- 摘述：工具可以是函式或 API，用於取得資料或執行操作；文件區分內建工具、MCP、API 管理與自訂函式等模式。

### 3. 記憶需要額外設計
- 摘述：文件說明短期記憶管理當次會話狀態，長期記憶可以跨對話保留資訊；記憶機制需要實作，不應說所有代理都必然具有長期記憶。
- 原文章節：Agent memory

### 4. 流程可以是 Graph
- 摘述：文件以單一代理、多代理及 graph-based workflows 說明不同的設計模式；越複雜的架構也會帶來成本與治理要求。
