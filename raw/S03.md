## 原文支持的主張（摘要）

### 1. 代理的基本循環
- 摘述：LangChain 將 Agent 描述為模型在任務未完成時，反覆使用工具的系統；工具回傳結果後，模型可繼續做決策。
- 原文章節：Agents：An agent is a model calling tools in a loop until a given task is complete.

### 2. 周邊配置（Harness）
- 摘述：文件同時說明，工具循環不是全部：提示詞、工具與 middleware 等周邊配置會塑造模型的行為。
- 原文章節：Agents：A harness is everything around that loop.
