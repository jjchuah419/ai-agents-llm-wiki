## 章節與可支持的主張

### 1. What is an agent?
- 來源位置：官方文章章節「What is an agent?」
- 摘要：OpenAI 將 Agent 描述為能在使用者授權範圍內，透過模型決策及工具使用來執行工作流程的系統。與只回覆文字的一般單輪聊天應用不同，模型參與流程控制。 [S01]

### 2. Agent design foundations
- 來源位置：官方文章章節「Agent design foundations」
- 摘要：基礎構件為模型（model）、工具（tools）及指示（instructions），其組合使系統能決策並與外部環境互動。 [S01]

### 3. When should you build an agent?
- 來源位置：官方文章章節「When should you build an agent?」
- 摘要：面對複雜判斷、不易維護的規則或非結構化資料時，可考慮代理；若確定性流程足夠，未必需要代理。 [S01]

### 4. Defining tools
- 來源位置：官方文章章節「Defining tools」
- 摘要：工具可協助讀取資料或執行動作，因此需要權限、驗證和風險控管。 [S01]
