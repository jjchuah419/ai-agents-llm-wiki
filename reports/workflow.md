# Wiki → HTML 的 Graph 與局部 Loop 實作說明

## Graph
需求確認 → 原文查核 → 兩篇 ingest（Stage1）→ 第一關驗證 → 三篇 ingest（Stage2）→ 全部來源覆蓋檢查 → 簡報資料表 → HTML 產生 → Python 靜態檢查 → 瀏覽器檢查 → 交件。

- 原文不可查／不支持主張：退回來源查核；補資料前不得進下一關。
- 條目無代碼或章節：退回對應 raw/wiki 條目；不是重做所有 5 篇。
- 文字偏離原始資料：退回該頁內容，保留其他已通過頁面。
- 版面有截字或互動出錯：退回 HTML/CSS，不重新 ingest。

## Loop
- 觸發：上述某關的 FAIL 或新增、修改資料。
- 行為：只修錯誤清單內的項目，再執行同一檢查。
- 停止：PASS；若 3 次仍 FAIL、缺來源或需人工判斷，停止並回報。
- 驗證：程式檢查、來源忠實度審查、瀏覽器驗證相互分開；不能用一種替代其餘兩種。
